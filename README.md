## 🚀 امکانات

### 🎵 موزیک
- جستجو با نام آهنگ یا خواننده (۵ نتیجه با دکمه‌ی دانلود جداگانه)
- دانلود با کیفیت ۱۲۸ / ۱۹۲ / ۳۲۰ (۳۲۰ ویژه‌ی اعضای VIP)
- دانلود مستقیم از لینک یوتیوب
- پلی‌لیست شخصی (افزودن، حذف، پاک‌سازی)
- آهنگ تصادفی بر اساس دسته‌بندی‌های محبوب
- رادیو آنلاین (۵ ایستگاه آماده)
- تبدیل متن به ویس (TTS فارسی)
- بعد از هر آهنگ: «آهنگ مشابه»، «افزودن به پلی‌لیست»، «تغییر کیفیت»

### 🤖 هوش مصنوعی
- چت هوشمند با حفظ زمینه‌ی گفتگو (۸ پیام آخر)
- ساخت عکس با پرامپت فارسی یا انگلیسی
- خلاصه‌سازی متن
- ترجمه‌ی هوشمند (۸ زبان)
- پرسش آزاد (پاسخ کوتاه و دقیق)

### 📥 دانلودر
- یوتیوب (ویدیو ۳۶۰/۴۸۰/۷۲۰/۱۰۸۰ و صدا)
- اینستاگرام (پست، ریلز، استوری)
- تیک‌تاک، روبینو، پینترست
- تشخیص خودکار نوع لینک + مدیریت حجم فایل

### 🛠 ابزارها
- فونت‌ساز با **۱۹ سبک** (۶ سبک کاملاً سازگار با فارسی)
- ماشین‌حساب امن (بدون `eval`، با توابع ریاضی)
- تبدیل واحد (طول، وزن، دما، زمان، داده، سرعت، مساحت، حجم)
- ساخت QR Code
- کوتاه‌کننده‌ی لینک
- استخراج متن از عکس (OCR)
- ساعت جهانی و تاریخ شمسی

### 🌤 کاربردی
- آب‌وهوای هر شهر (۳ روز پیش‌بینی، بدون نیاز به کلید)
- نرخ ارز، طلا، سکه
- قیمت ارزهای دیجیتال
- ساعت و تاریخ ایران + جهانی

### 🎮 سرگرمی
- جوک، شعر، فال حافظ (فال روزانه + تصادفی)
- بازی: حدس عدد، سنگ‌کاغذقیچی، تاس
- چالش روزانه
- ساخت استیکر با هوش مصنوعی (۶ دسته + متن دلخواه)

### ⚙️ مدیریت گروه
- پیام خوش‌آمدگویی قابل تنظیم (با متغیر `{name}` و `{group}`)
- ضد لینک، ضد اسپم، حذف فوروارد
- سیستم اخطار با سقف قابل تنظیم (خودکار → حذف)
- قفل گروه
- آمار گروه و فعال‌ترین اعضا
- دستورات: `/warn` `/unwarn` `/ban` `/unban`

### 💎 عضویت ویژه
- پلن‌های ماهانه / سه‌ماهه / شش‌ماهه
- حذف محدودیت روزانه، کیفیت بالاتر، ابزارهای اختصاصی
- نمایش وضعیت اشتراک در پروفایل
- خرید داخل ربات: ارسال رسید ← تأیید/رد توسط ادمین ← فعال‌سازی خودکار

### 👑 پنل ادمین
- آمار کاربران (کل، فعال ۷/۳۰ روز)، اعضای ویژه، پر‌مصرف‌ترین بخش‌ها
- مدیریت اشتراک‌ها و رسیدهای در انتظار (تأیید/رد با یک دکمه)
- ارسال پیام همگانی
- مشاهده‌ی لاگ خطاها
- روشن/خاموش کردن هر بخش بدون ری‌استارت
- جستجوی کاربر و اعطای اشتراک

## 🛠 نصب و راه‌اندازی

### پیش‌نیازها
```
Python 3.10+      •   اینترنت   •   توکن ربات از @BotFather در روبیکا
```

### ۱) دریافت توکن
1. در روبیکا به [@BotFather](https://rubika.ir/BotFather) برو
2. بات بساز و توکن را کپی کن

### ۲) نصب
```bash
git clone https://github.com/<your-username>/astra-bot.git
cd astra-bot

python -m venv .venv
source .venv/bin/activate        # ویندوز: .venv\Scripts\activate

pip install -r requirements.txt
```

### ۳) تنظیم `.env`
```bash
cp .env.example .env
nano .env          # توکن و شناسه‌ی ادمین را وارد کن
```

حداقل تنظیمات لازم:
```env
BOT_TOKEN=توکنی_که_از_بات_فادر_گرفتی
ADMIN_IDS=شناسه_کاربری_خودت
```

> بعد از اولین اجرا، داخل ربات `/id` را بزن تا شناسه‌ات را بگیری و در `ADMIN_IDS` قرار بدهی.

### ۴) (اختیاری) فعال‌سازی امکانات بیشتر
```bash
pip install "qrcode[pil]" gTTS     # QR محلی + تبدیل متن به ویس
sudo apt install ffmpeg            # برای yt-dlp
pip install -U yt-dlp              # جستجو/دانلود موسیقی و ویدیو
```

## 🔧 تنظیمات (.env)

| کلید | توضیح | پیش‌فرض |
|---|---|---|
| `BOT_TOKEN` | توکن ربات از BotFather | — (اجباری) |
| `ADMIN_IDS` | شناسه‌ی ادمین‌ها (با کاما جدا شود) | خالی |
| `SUPPORT_ID` | شناسه‌ی پشتیبان برای پیام‌ها | اولین ادمین |
| `AI_API_KEY` | کلید سرویس OpenAI-like (اختیاری) | خالی |
| `AI_BASE_URL` | آدرس سرویس مدل | `https://api.openai.com/v1` |
| `AI_MODEL` | نام مدل | `gpt-4o-mini` |
| `VIP_PRICE_1/3/6` | قیمت پلن‌ها | ۴۹/۱۲۹/۲۲۹ هزار تومان |
| `CARD_NUMBER` `CARD_OWNER` | اطلاعات پرداخت | خالی |
| `POLL_INTERVAL` | فاصله‌ی دریافت آپدیت (ثانیه) | `2` |
| `REQUEST_TIMEOUT` | تایم‌اوت درخواست‌ها | `15` |
| `MAX_UPLOAD_MB` | سقف حجم فایل ارسالی | `45` |

محدودیت‌های روزانه برای کاربران عادی (در `config.py` قابل تغییر):
`ai_chat: 15` · `ai_image: 5` · `download: 8` · `music: 10` · `tts: 8` · `ocr: 5` · `qr: 20`
(اعضای ویژه نامحدود ♾)

## ▶️ اجرا

```bash
python main.py              # اجرا با Long Polling
python main.py --check      # فقط بررسی توکن و اتصال
python main.py --once       # یک دور دریافت آپدیت و خروج
python main.py -v           # با لاگ کامل
```

اجرای دائمی روی سرور (systemd):
```ini
[Unit]
Description=Astra Rubika Bot
After=network.target

[Service]
WorkingDirectory=/root/astra-bot
ExecStart=/root/astra-bot/.venv/bin/python main.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

اگر سرور دامنه و SSL دارد، وب‌هوک سریع‌تر است:
```bash
python main.py --webhook https://example.com/astra-webhook
```

## ➕ افزودن ابزار جدید

معماری ربات افزونه‌پذیر است؛ برای یک ابزار تازه ۳ مرحله کافی است:

**۱. سرویس** (`astra/services/myservice.py`)
```python
def do_something(text: str) -> str:
    return "نتیجه"
```

**۲. handler** (مثلاً در `astra/handlers/tools.py`)
```python
from ..core.router import route, state
from ..core.keyboards import btn, kb
from ..services import myservice

@route("tools:mytool")                      # دکمه: "tools:mytool"
@guarded("tools.mytool")                    # مدیریت خطای خودکار
def my_tool(ctx):
    enter(ctx, "tools:mytool")              # ثبت در پشته‌ی بازگشت
    ctx.set_state("await_mytool")           # انتظار ورودی کاربر
    ctx.answer("🔧 مقدار را بفرست:",
               kb().row(btn("❌ انصراف", "nav:back")).build())

@state("await_mytool")                      # پاسخ به ورودی کاربر
@guarded("tools.mytool_do")
def my_tool_do(ctx):
    ctx.clear_state()
    ctx.send(myservice.do_something(ctx.text))
```

**۳. دکمه در منو** — در همان فایل، یک سطر به کیبورد اضافه کن:
```python
.row(btn("🔧 ابزار من", "tools:mytool"), btn("...", "..."))
```
سپس `python simulate.py` را اجرا کن تا مطمئن شوی مسیر جدید بن‌بست ندارد.

## 🧪 تست و کیفیت

شبیه‌ساز، **همه‌ی منوها و دکمه‌ها را به‌صورت خودکار پیمایش می‌کند**،
بدون نیاز به توکن یا اینترنت:

```bash
python simulate.py            # حالت آفلاین (سریع)
python simulate.py --online   # با فراخوانی سرویس‌های واقعی
```

خروجی نمونه:
```
▫️ routes               94
▫️ states               24
▫️ commands             24
▫️ visited_callbacks    108
▫️ بن‌بست‌ها            0
▫️ خطاها                0
✅ همه‌ی مسیرها سالم و بدون بن‌بست هستند.
```

چه چیزهایی بررسی می‌شود:
- هر callback handler دارد (بن‌بست صفر)
- هیچ پیام خالی ارسال نمی‌شود
- خطاها به‌صورت پیام کاربرپسند نمایش داده می‌شوند (نه crash)
- سناریوهای متنی (زبان طبیعی) و سناریوهای گروهی

## 🔒 نکات فنی و امنیت

- **`.env` هرگز کامیت نمی‌شود** و در `.gitignore` است.
- اگر توکنی در چت، لاگ یا جای عمومی منتشر شد، از BotFather آن را **Revoke** کن.
- درخواست‌های شبکه همگی تایم‌اوت و تلاشِ مجدد دارند (`services/http.py`).
- خطاها در جدول `logs` ذخیره می‌شوند و از پنل ادمین قابل مشاهده‌اند.
- پردازش آپدیت‌ها با ThreadPool انجام می‌شود، پس ربات زیر بار سنگین پاسخ‌گو می‌ماند.
- ماشین‌حساب از `eval` استفاده نمی‌کند (`ast` سفید‌لیست‌شده).
- اگر `yt-dlp` یا کلید AI نصب/تنظیم نباشد، ربات پیام راهنما می‌دهد؛ هیچ‌وقت خطای خام نمی‌بیند.
